Some **Teams Pro** capabilities appear in our plan catalog and pricing comparisons before the product UI ships. This page lists what is **coming soon** so you are not surprised at checkout.

## When to use this

* You saw a Teams Pro feature on pricing and cannot find it in the app
* Procurement wants to know what is shipped vs catalog-only
* You are evaluating bulk send, webhooks, or custom branding
* You want the status of recipient-side sender approval

## How it works

### Available today

These Teams Pro features work in the app now:

* Sequential signing **turn order**
* **Quorum** (minimum signatures required)
* **Multi-recipient** payout rules
* **Per-packet recipient selection** for gated files
* **Signature-conditional** gated file release
* Higher monthly document quota and signer limits

### Coming soon

| Feature | Intended plan | Status |
|---------|---------------|--------|
| Bulk send from CSV | Teams Pro+ | Catalog only, no UI |
| Webhook notifications | Teams Pro+ | Catalog only (not the same as billing webhooks) |
| Custom sign-page branding | Teams Pro+ | Catalog only |
| Seat quota allocation | Teams Pro+ | Catalog only |
| Shared template folders | Teams Pro+ | Catalog only |
| Envelope metadata tags | Teams Pro+ | Catalog only |
| Custom integrations / embed API | Teams Pro+ | Catalog only |

We will update this page and [Plans and limits](/docs/plans/) when each feature ships.

### Recipient sender approval

Marketing describes recipients **approving who may send** them documents. Sender-side contact lists and recipient-side approval are **catalog / roadmap only** and not in the app yet.

## Example workflow

A buyer compares Teams Pro on the pricing page against the product UI. They confirm turn order and quorum are live, note bulk send is catalog-only, and email support to request webhook notifications.

## What to watch out for

* Catalog-only features may appear in plan comparisons before UI ships.
* Billing webhooks are not the same as workflow webhook notifications on this roadmap.
* Enterprise customers can scope custom work through [sales@filosign.xyz](mailto:sales@filosign.xyz).
