Some **Teams Pro** capabilities appear in our plan catalog and pricing comparisons before the product UI ships. This page lists what is **coming soon** so you are not surprised at checkout.

## Available today

These Teams Pro features work in the app now:

- Sequential signing **turn order**
- **Quorum** (minimum signatures required)
- **Multi-recipient** payout rules
- **Per-packet recipient selection** for gated files
- **Signature-conditional** gated file release
- Higher monthly document quota and signer limits

See [Plans and limits](/docs/plans/) and workflow guides for details.

## Recipient sender approval

Marketing describes recipients **approving who may send** them documents. Sender-side **Connections** and invites work today; full recipient-side approval is still rolling out. See [Connections](/docs/workspace/connections/).
