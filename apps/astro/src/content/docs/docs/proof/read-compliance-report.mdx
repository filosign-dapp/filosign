## What is this PDF?

The **proof report** is a readable summary of one signing workflow. Download it alone or inside the [proof packet](/docs/proof/completion-packet/).

Use it when someone asks: "Who signed this, when, and what did they complete?"

## Start here (most readers)

1. **Parties**: Does the sender and signer list match who you expected?
2. **Signer matrix**: Did each required person sign? What time is shown?
3. **Field placements**: Were the right signature, date, and text fields completed?
4. **Status**: Does it say **completed** or **voided**?

If those four look right, the report usually answers day-to-day questions.

## Optional sections

### Payout packets and gated files

Only if the sender added **payout packets** or **gated files**. Confirms what was attached and whether payouts ran.

### Transaction links

Clickable references for technical reviewers. You can ignore these unless audit or counsel asks for independent verification.

## Which download should I use?

| Need | Download |
|------|----------|
| Email one file to a client | Document with proof PDF |
| Internal legal review | Proof report only |
| Full archive | Proof packet ZIP |

## Compared to a DocuSign certificate

Traditional tools attach a certificate PDF to the signed file. Filosign separates the **signed document** and a **detailed report** so finance and legal can review evidence without parsing the contract file itself.
