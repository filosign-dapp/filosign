title: Agreement workflows

A Filosign workflow starts with a document, but it does not have to end with a signature. You can collect signatures, export proof, release files, and attach payout packets based on the conditions you choose.

## Workflow lifecycle

1. **Compose**: Prepare the document, add recipients, place signature fields, and optionally attach payout packets or gated files.
2. **Send**: Deliver invitations securely.
3. **Sign**: Collect signatures in parallel or using a sequential signing order.
4. **Prove**: Download the completed proof packet with the audit trail and verification references.
5. **Release**: Signing conditions automatically trigger next steps—USDC payout packets are executed, or gated files are decrypted and unlocked.

## What unlocks after signing

* **Payout packets**: Pay contractors, distribute grants, or resolve bounties automatically. Approved USDC transfers execute directly from your wallet when signing conditions are satisfied.
* **Gated file release**: Release deliverables, source code, or sensitive annexes only after you receive the client's signature or HR approvals.

## Example workflows

* **Grant Milestones**: A grant manager sends a milestone report to a recipient. When both parties sign, the agreement is complete, and the attached payout packet automatically releases the USDC grant funding from the program's linked treasury.
* **Contractor Delivery**: An agency sends an acceptance form along with final design assets as a gated file packet. When the client signs, the assets unlock for download.
* **Bounty Payouts**: A developer signs a completion waiver, which automatically triggers a bounty USDC payment upon HR signature.
