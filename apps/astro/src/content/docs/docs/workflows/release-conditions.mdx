Release conditions answer one question: **when should this happen?**

* For payout packets, you set **Pay out when**.
* For gated files (when unlock is **Conditions are met**), you set **Unlock when**.

Payout packets and gated files share the same list of release condition options.

## When to use this

* You are attaching a payout packet and need to pick **Pay out when**
* You are adding gated files with **Conditions are met** unlock
* Two condition labels sound similar and you want to know which to pick
* You need to understand what happens automatically when a condition is met

## How it works

You do not press a button. Filosign handles it after signatures, as signing progress updates.

| Feature | What Filosign does |
|---|---|
| **Payout packets** | Moves approved USDC from the payer wallet to each recipient in that payout packet. See [Payout packets](/docs/workflows/payouts/). |
| **Gated files** | Unlocks the file packet so chosen recipients can download. See [Gated file release](/docs/workflows/attached-files/). |

**Right after send** file packets ignore release conditions. They unlock as soon as the envelope is sent.

### All release options

| Option in the app | What has to happen |
|---|---|
| **Everyone has signed** | The envelope is fully complete under its signing order |
| **A specific person signs** | One signer you pick has signed |
| **Enough people sign** | At least **N** people on the envelope have signed (you enter **N**) |
| **Everyone required has signed** | Every required signer has signed |
| **Everyone (including optional) has signed** | Required and optional signers have all signed |
| **Envelope minimum signatures are met** | The envelope hits its minimum signature count (you enter **N** if needed) |
| **Enough people from your chosen group sign** | At least **N** people from the roster have signed |
| **Enough people from the full roster sign** | At least **N** people from the full signer list have signed |
| **Everyone on your list signs** | Every signer on the roster has signed |

### Extra fields you may see

**Which signer triggers payout** appears when you pick **A specific person signs** for a payout packet.

**How many signatures are needed** appears for options that use a number.

**Cutoff date (optional)** appears when you attach a payout packet. Gated file packets do not offer a cutoff date in the compose dialog today.

## Example workflow

An HR team sends a bonus waiver to an employee and manager. The payout packet uses **Pay out when: A specific person signs** with the manager selected. When the manager signs, USDC sends to the employee even if optional viewers have not opened the document.

## What to watch out for

* Some options sound different but fire at the same milestone depending on who is on the envelope. Pick the label that best matches what you mean.
* Group options use the full signer list. You cannot pick a custom subgroup in the UI today.
* If a payout fails (not enough USDC, approval removed), the sign page may show **Pay now** so you can retry.
* Turn order and minimum signatures from [Signing and routing](/docs/workflows/signing-and-routing/) affect when "everyone has signed" is satisfied.

## How to pick a condition in the app

1. While attaching a payout packet or gated file packet, open the **Pay out when** or **Unlock when** dropdown.
2. Choose the condition that matches your business rule.
3. Fill in **N** or pick a specific signer if the option asks for it.
4. For payouts, optionally set a **Cutoff date**.
