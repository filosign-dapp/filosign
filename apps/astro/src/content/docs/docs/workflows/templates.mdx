title: Templates

**Templates** are reusable envelope blueprints for your workspace. They store the PDF, signature field layout, and template roles so senders can start a new envelope without rebuilding the same setup.

## When to use this

* Your team sends the same NDA, SOW, or policy repeatedly
* You want the same field layout every time, not just the same PDF
* You need a faster starting point before assigning real recipients and sending

## How it works

A template stores:

* A **name** (for example, **Standard NDA**)
* One or more **encrypted PDFs**
* **Template roles** (Signer 1, Signer 2, and so on) instead of real email addresses
* **Placed fields** tied to those roles
* Optional default subject and message in the blueprint

When someone **uses** a template, Filosign asks them to assign each role to a real person, decrypts the template PDFs, rotates encryption keys for the new envelope, and opens the designer with fields already placed.

| | Draft | Template |
|---|-------|----------|
| Best for | Work in progress | Reusable team blueprint |
| Holds | Full envelope setup | Roles, fields, PDFs, defaults |
| Lifecycle | Until sent or deleted | Stays in the library |

## Example workflow

A sales team saves their mutual NDA as a template with two signer roles and eight signature fields. For each deal, a sender clicks **Use template**, assigns the prospect and counterparty, reviews the pre-placed fields, and sends.

## What to watch out for

* Templates stay inside your workspace. They are not public links.
* Deleting a template removes it from the library. Envelopes you already sent from that template are not affected.
* Viewers can browse the template library but cannot use, edit, or delete templates.

## How to use templates in the app

### Create a template

**From the Templates page (recommended):**

1. Click **New template** and upload one or more PDFs.
2. Open the template editor at `/dashboard/templates/new` to add roles, documents, defaults, and place fields.
3. Click **Save template** and name it.

**From a saved draft (shortcut):**

1. Open a saved draft in the send designer.
2. Choose **Save as template** from the draft menu and enter a name.

### Edit a template

1. On **Templates**, click **Edit** (owner or admin only).
2. The editor opens at `/dashboard/templates/{id}/edit` where you can update roles, documents, defaults, and field placement.
3. Click **Save template**.

### Use a template

1. On **Templates**, click **Use template** (owner, admin, or sender).
2. Assign each template role (signers and optional viewers) to a real person.
3. Review pre-placed fields in the send designer, attach payouts or extra files if needed, then send or save as a draft.

### Who can do what

| Role | Access |
|------|--------|
| Owner / admin | Create, edit, delete, and use templates |
| Sender | Use templates only |
| Viewer | Read-only library (list and metadata) |
