Workspace **members** share drafts, templates, and team-visible envelopes. Each person has a **role** that controls what they can do.

## When to use this

* You are inviting a colleague and need to pick the right role
* You want to know who can void envelopes or manage billing
* A new member shows **Encryption key pending** and cannot open team drafts yet
* You are deciding between Sender and Viewer for a teammate

## How it works

| Role | Typical use |
|------|-------------|
| **Owner** | Created the workspace; full control including billing |
| **Admin** | Manages members, billing, templates, and governance |
| **Sender** | Sends envelopes and uses shared drafts and templates |
| **Viewer** | Reads team envelopes and drafts; cannot send |

Owners and admins can void incomplete envelopes, amend signers, and manage supplementary attachment rules. Senders send on behalf of the org but cannot override those governance actions. See [Envelope governance](/docs/workflows/envelope-governance/).

Team drafts and team envelope visibility require a **Teams** or **Teams Pro** plan.

## Example workflow

A growing agency adds a paralegal as **Viewer** so they can read team envelopes without sending, and promotes an operations lead to **Admin** so they can manage billing and void in-progress agreements.

## What to watch out for

* New members need to unlock encryption keys before they can open team drafts or envelopes.
* Removing someone does not delete envelopes they already sent or signed.

## How to manage members in the app

### Invite a teammate

1. Open **Workspace settings** → **Team members**.
2. Click **Invite member**.
3. Enter their email and pick a role.
4. Send the invite.

### Change or remove a member

Owners and admins can update roles or remove members from **Team members**.

### Permissions by role

| Action | Owner | Admin | Sender | Viewer |
|--------|:-----:|:-----:|:------:|:------:|
| Manage billing | ✓ | ✓ | | |
| Invite / remove members | ✓ | ✓ | | |
| Create shared templates | ✓ | ✓ | | |
| Send envelopes | ✓ | ✓ | ✓ | |
| Read team envelopes | ✓ | ✓ | ✓ | ✓ |
| Write team drafts | ✓ | ✓ | ✓ | |
| Share drafts externally | ✓ | ✓ | ✓ | |
