title: Signature no longer valid

---

## Why you see this

Filosign verified your signature request but the blockchain rejected it. This usually happens if the signature was delayed, or if the transaction expired during a network congestion.

## What to do

1. Return to the document signing page.
2. Verify all your fields are filled.
3. Tap **Sign** again to generate a new transaction.

## Still stuck?

If the signature keeps failing, refresh the page to sync the current block height and nonce information, then try again.
